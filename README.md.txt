# Pune Price War: Kirana vs DMart vs Blinkit - BSc Stats Project

#### BSc Statistics Practical 2025-26 | Pune

**Objective:** Compare grocery prices to find cheapest channel.

**Dataset:** 15 items, 45 price points collected 22 Sept 2026 from Kirana, DMart Aundh, Blinkit App.

**Results:**
- DMart Mean = Rs 59.06 (Cheapest)
- Kirana Mean = Rs 63.26
- Blinkit Mean = Rs 70.40
- ANOVA: F=0.32, p=0.73 - Practically DMart saves Rs 330/month

**Files:**
- price_comparison.csv - Raw data
- analysis.py - Python code
- price_barchart.png - Bar chart
